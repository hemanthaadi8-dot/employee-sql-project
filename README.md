# Employee SQL Practice Project

## About This Project
This repository contains my hands-on SQL practice using MySQL. It covers fundamental and intermediate SQL concepts using an employee database and practical query examples.

## Technologies Used
- MySQL 8.0
- SQL
- GitHub

## Database Structure
The practice queries use an employee table with columns such as:
- `emp_id`
- `name`
- `department`
- `location`
- `salary`
- `joining_date`
- `age`
- `manager_id`

A departments table is also used for join practice.

## SQL Concepts Covered
- SELECT, WHERE, ORDER BY and DISTINCT
- Filtering with AND, OR, IN, BETWEEN and LIKE
- LIMIT and OFFSET
- Aggregate functions: COUNT, SUM, AVG, MIN and MAX
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN and RIGHT JOIN
- FULL OUTER JOIN workaround in MySQL
- SELF JOIN and CROSS JOIN
- Subqueries and correlated subqueries
- EXISTS and NOT EXISTS
- CASE WHEN and COALESCE
- Date functions and date filtering
- Common Table Expressions (CTEs)
- SQL interview and LeetCode-style problems

## Files
- `sql_practice_topics.sql` — A collection of SQL examples organized by topic.

## How to Practice
1. Install MySQL 8.0 or use an existing MySQL installation.
2. Create or select a database named `company_db`.
3. Ensure the required tables and sample data exist.
4. Open the SQL file and execute the relevant queries individually.

**Note:** The SQL examples assume the employee database and its tables are available. Some practice questions use separate table structures and may need their own setup before execution.

## Learning Goals
- Improve SQL query-writing skills.
- Understand joins, subqueries and aggregations.
- Practise solving SQL interview questions.
- Build a portfolio for entry-level SQL, Data Analyst and Data Engineering opportunities.
